# 通用部署验证记录

日期：2026-11-19。实际系统为 Windows，Python 3.12；没有在本轮声称完成 macOS/Linux 系统验收。

## 本轮实测

- 从公开源码复制出全新目录，目录名含中文与空格，测试从另外一个工作目录启动。
- 使用标准库建立独立 `.venv`，未安装媒体依赖、模型和平台账号。
- 初始化空白账号与登记表，重复 init 保留已有数据。
- 启动离线服务，健康接口返回新副本根目录；首页、前端脚本、账号、项目、动作和 Skill 接口可读。
- 在新副本通过 HTTP 创建图片项目、保存制作要求，四个随库分发的自有 Skill 形成 READY_FOR_CODEX 计划。
- 队列保持 WAITING_APPROVAL；没有调用图像工具、付费服务或执行发布。
- 验证 DOUYIN_PROJECT_ROOT 覆盖与缺失显式工具路径的处理。

## 测试结果

完整 Python 测试 **147 项通过**。真实媒体探测项使用已有 FFmpeg/ffprobe 并显式传入路径；平台生成响应采用模拟数据。前端三个测试文件 **24 项通过**。PowerShell 入口语法检查通过。

独立部署测试不借用原作者的 content、research、账号、审批或全局 Skills。测试使用的媒体为临时合成视频；网络访问仅用于本机 HTTP 接口和模拟的服务适配逻辑。
