# 制作流程与操作说明

## 一个项目从哪里开始

先创建账号档案，再在制作中心选择图片或视频。账号档案用于本地筛选项目、定位与允许主题；不会切换抖音 Cookie。图片和视频共用页面、素材库与发布准备，项目创建后内容路线固定。

一次制作要求建议写明：主题、目标受众、观众能得到什么、风格、图数或视频总时长、画幅、人物与文字、声音、参考素材用途，以及不能出现的内容。

例如图片：`一张雨后海岸照片，9:16，自然治愈，湿礁石与灰蓝海浪，像真实相机拍摄，无人物、无文字。`

例如视频：`5秒单镜头，9:16，固定低机位看海浪退去，阴天散射光，无人物、无对白、无字幕、无配乐；先生成任务卡并核对费用。`

网页输入会自动保存草稿。保存草稿不会生成媒体。正式保存要求后生成 `workbench_request.json`、`skill_plan.json`、素材策略和队列回执。缺失 Skill 会显示阻塞原因。

## 素材怎么使用

素材库支持常见图片、视频与音频，单文件上限 512 MB。导入会复制到 `assets/library/<asset_id>/`，并写入本地索引。项目绑定素材 ID，避免同一素材在不同项目中含义混淆。

应说明用途：构图、色彩、角色身份、场景、首尾帧、运镜、声音或事实来源。再写清可保留项、必须修改项，以及是否允许上传到外部模型。

| 策略 | 使用场景 |
| --- | --- |
| NONE | 纯主题生成，不依赖参考 |
| USE_EXISTING | 使用已有可用素材 |
| GENERATE_KEYFRAMES | 先稳定首尾帧或场景 |
| GENERATE_ELEMENTS | 先稳定角色、产品或局部元素 |
| EXTRACT_FROM_REFERENCE | 从参考视频提取关键帧 |
| MIXED | 已有与新生成素材组合 |

策略文件表达需要什么，具体执行仍需制作方完成。例如写入 EXTRACT_FROM_REFERENCE 本身不会提取视频。

## 图片路线 IMAGE_CAROUSEL

1. 确认 brief：主题、图数、视觉风格、每图变化、文字和禁区。
2. 路由器选择一个主视觉 Skill，加上编排、导演提示词、图片生成、高清导出。只选需要的能力。
3. Codex 读取相关 Skill 与 brief，形成逐图提示词、系列不变量和验收要求。
4. 批准齐备且 Skill 可用后，图片队列进入 READY。Codex 用 `src/codex_dispatcher.py claim` 领取，再调用可用的内置图片工具。
5. 保存原图、逐图提示词和制作清单，导出发布图片与手机预览。失败图单独替换，保留关系。
6. 进行机器 QA 和独立内容 QA，用户验收完整批次。
7. 将最终图序、标题、短文案、配乐策略与 QA 组成发布包。

典型产物包括 `production/prompt_package.*`、`production/generated/`、`production/publish_images/`、`qa/technical_report.json` 和 `qa/qa_result.json`。实际文件以项目 manifest 为准。

Codex 的内置图片能力由运行会话提供，工作台 Python 服务不会凭 Skill 文件启动图片模型。没有执行会话时页面会继续等待。首次尝试一种新风格，建议先制作一张代表图，用户接受后再扩展系列。

## 氛围视频路线 ATMOSPHERE_VIDEO

1. 确定观众收益、总时长、画幅、场景和声音策略。
2. 编写镜头表，每镜明确时段、主体动作、构图、运镜、光线与验收句。判断是否需要图片锚点。
3. 导演 Skill 输出 `prompt_package.md/json`；服务商编译器把共同导演语言转换为目标平台提示词。
4. 生成视频任务确认卡，检查平台、模型、时长、分辨率、素材、积分和当前批准。
5. Flova 可由已配置的官方 CLI 执行；即梦/Seedance 和 H3 独立入口当前通过平台人工或浏览器交接执行。
6. 取回真实视频文件，检查文件非空、可解码、时长和画幅；链接、ZIP 或进程退出不代表交付完成。
7. 按需剪辑、合成、配音、字幕、配乐与调色。单镜头无对白时允许直接验收镜头，不强制建立 Remotion 工程。
8. 完成质量检查、人工验收和发布包。

外部模型成功出片与本地导出成功分别记录。Flova 运行 ID、项目 ID、导出任务 ID 用于恢复原任务；页面重试不应再次购买同一镜头。需要平台选择时应展示原始选项，由用户决定。

模型可用性、时长和价格随平台变化；编译器里的支持配置是当前实现的校验范围，不是最新官方套餐承诺，正式生成前以实际页面或官方接口报价为准。

## 讲解视频路线 NARRATED_EXPLAINER

在视频路线基础上增加事实脚本、来源、逐镜证据、旁白、字幕和声音权利。先生成或录制 8–15 秒声音样本，确认自然度后再制作完整旁白。配音 Skill 存在不代表已配置账号和费用。

字幕需要真实时间戳或人工对齐，检查断句、字号、安全区和同步。Remotion 与 FFmpeg 用于后期，不能把静态图片推拉当作已经完成模型生成。

## 验收、发布与数据

机器检查关注规格与可探测异常；独立 QA 检查内容、真实感、连续性、可读性、节奏和手机效果。最终审美由用户接受具体版本。改动图片、顺序、文字或声音后，要更新发布包和相关批准。

prepare-only 将准备步骤停在发布按钮前。当前网页的 social-auto-upload 动作只生成命令预览；平台登录、验证码、音乐选择和实际上传仍需明确交接。最终发布由用户手动完成，或在动作前明确授权。

发布后记录真实作品 URL、标题、时间与回执。FIRST_VISIBLE 是首次确认身份且数据可见；H24 窗口是 22–28 小时；H72 是 68–84 小时。不可见字段留空，超窗标 LATE，不编造历史数据。复盘结论为 KEEP、STOP 或 INCONCLUSIVE，下一条只改变一个主变量。

生产审批链与状态转换命令见 `workflow/MASTER_WORKFLOW.md`。空白安装缺少真实研究与批准时，生产审计会阻断推进，但仍可启动网页和管理项目。
