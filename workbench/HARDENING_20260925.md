# 工作台使用稳定性改进 · 2026-09-25

## 已完成

- 启动器使用相对路径和 ASCII 脚本，适配 Windows PowerShell 5.1 与中文项目目录。支持 `-NoBrowser`、`-Port`、`-Offline`，复用服务前检查项目目录及模式，保留逐次启动日志。
- 修复新建项目成功后访问已失效的 `event.currentTarget` 导致前端误报失败的问题；重复提交期间禁用按钮，错误就地显示。
- 新建项目在初始化前固定账号归属，避免初始化期间切换账号造成项目归错档。
- 制作表单回填 `production/workbench_request.json` 的已保存参数；按账号、项目、动作分别暂存未提交输入，保留空值、0 和取消素材选择。执行确认不自动沿用。
- 保存完成时比较提交内容与当前输入，保留执行期间继续填写的修改。
- 新建图片/视频切换保留标题等输入；收起新建区恢复已有项目；项目详情跳回制作中心时退出新建模式。
- 任务记录按项目请求，覆盖较旧项目；结果区显示简短状态，完整日志可展开。旧页面的异步返回不会覆盖新页面。
- 增加请求超时和连接失败恢复入口；客户端关闭页面导致的 socket 断开不再触发重复 500，业务异常仍正常报告。
- 制作表单前只保留当前任务选择，完整工具用途折叠展示；策略选项显示中文；手机导航折叠，输入字号适配手机。
- 流程规范的视频路线说明统一为 Flova / Seedance / MiniMax H3。

## 使用边界与后续缺口

- 未提交草稿暂存在当前标签页内，刷新/关闭会丢失；已保存制作参数可重新载入。
- 启动器用于双击恢复和当前登录会话后台运行；未设置 Windows 开机自启，也未验证重启电脑后自动恢复。
- 本轮只验证工作台的本地功能，未调用付费生成服务。外部视频服务真实生成、结果回传、成片验收仍需一次具体视频项目的端到端验证。
- 抖音上传当前仍经 prepare-only 交接和创作者中心完成，工作台的上传命令预览不可执行；最终发布由用户确认执行。
- 本轮未修改作品状态、发布记录、审批或指标，未新增模型/依赖下载。
